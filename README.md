# ECSE 4320/6320 Class-wide Projects

All measurements were taken on an Intel Core i3-6100U laptop (2 cores / 4 threads) with a SATA SSD, running Ubuntu (Linux 6.11).

| Folder | Project | Report |
|---|---|---|
| `proj1/` | SIMD Advantage Profiling | [`proj1/report.html`](proj1/report.html) |
| `proj2/` | Cache & Memory Performance Profiling | [`proj2/report.html`](proj2/report.html) |
| `proj3/` | SSD Performance Profiling | [`proj3/report.html`](proj3/report.html) |

Each folder's `README.md` explains how to run that project.

`AI_USE_NOTES.md` describes how AI tools were used across all three projects.

Each `report.html` loads the PNGs next to it, so open it from inside its project folder. To regenerate the plots, run that project's `analyze.py`.
